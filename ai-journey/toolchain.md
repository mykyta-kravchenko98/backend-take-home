# AI toolchain

This repository was prepared through a sequence of five Codex chats using the checked-in prompts under `ai-journey/prompts/`.

## Tools actually used

- Codex desktop coding agent.
- GPT-5 family model supplied by the Codex environment. The UI did not expose a more specific model identifier to record reliably.
- PowerShell for repository inspection and command execution.
- .NET SDK and CLI for restore, formatting verification, build, test, and local execution checks.
- Git CLI for working-tree inspection.
- Codex file patching and task-planning tools for controlled edits and progress tracking.

## Skills and MCP servers

- Codex skills: none used.
- MCP servers/connectors: none used.

No externally installed plugin or connected service was needed for the implementation.
